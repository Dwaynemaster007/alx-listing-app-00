# 🏠 ALX Listing App 00

The starting point of an Airbnb-style property listing app, built with **Next.js** and **TypeScript** for the **ALX ProDev Frontend** programme.

![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=flat-square&logo=tailwindcss&logoColor=white)

## Features

- Home page with a hero section and **filter pills** for property categories
- A reusable `PropertyCard` grid fed from typed sample data in `constants/`
- Shared `Header`, `Footer` and `Layout` components
- A booking page with `BookingForm`, `OrderSummary` and `CancellationPolicy`
- Type-safe props with interfaces in `interfaces/index.ts`

## Structure

```
components/   PropertyCard, Pill, layout/, booking/
constants/    sample property data
interfaces/   TypeScript interfaces
pages/        index.tsx, booking/index.tsx
```
